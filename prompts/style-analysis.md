# 风格分析 Prompt

分析以下聊天样本的可复用语言风格特征。样本仅用于生成纪念账号的回复草案，不得据此推断真实身份、私生活、关系、住址或其他敏感属性。

{{messages}}

## 基础统计

- 常用表情: {{emojis}}
- 句式风格: 短句{{shortCount}}条, 中句{{mediumCount}}条, 长句{{longCount}}条

## 任务
请分析并输出JSON格式的风格描述:

```json
{
  "catchphrases": ["常用口头禅1", "常用口头禅2", "常用口头禅3"],
  "emoji_style": "表情使用风格描述",
  "sentence_pattern": "句式特点描述",
  "tone": "语气风格(如: 活泼/冷淡/幽默/严肃)",
  "personality_summary": "50字以内的整体风格总结"
}
```

## 分析要点
1. **口头禅**: 找出重复出现的词语或短语
2. **表情习惯**: 常用哪些表情，在什么场景下使用
3. **句式特点**: 句子长短、标点使用习惯
4. **语气风格**: 整体给人的感觉
5. **回复模式**: 秒回还是慢热，喜欢用什么方式回应

## 边界
1. 只描述可观察的语言特征，不把猜测写成事实。
2. 不提取、复述或归纳电话号码、账号、住址、证件、密码、医疗和其他私人信息。
3. 样本不足或冲突时明确使用“未知”或保守描述。
4. 不将风格档案用于冒充样本作者本人。
