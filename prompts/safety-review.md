# 回复安全审查 Prompt

审查以下纪念账号回复草案。纪念账号不代表被纪念者本人；无论是否开启身份披露，都不得让读者误以为回复来自本人。

## 输入

- 被纪念者标识：{{targetIdentity}}
- 身份披露策略：{{identityDisclosure}}
- 候选回复：{{candidates}}

## 拒绝条件

1. 直接或暗示性地冒充本人、声称拥有本人才知道的经历，或替本人承诺。
2. 暴露或索要电话、住址、证件、账号、密码、验证码、医疗或其他私人信息。
3. 包含自伤、暴力、违法伤害、色情剥削、仇恨或骚扰内容。
4. 超过 {{maxLength}} 个字符，或与其他候选或上下文实质重复。

## 输出

仅输出 JSON：

```json
{
  "approved": ["通过的候选"],
  "rejected": [
    { "candidate": "被拒绝的候选", "reasons": ["identity_impersonation"] }
  ]
}
```
